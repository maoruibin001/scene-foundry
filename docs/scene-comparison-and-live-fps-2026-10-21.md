# 同屏参考对比与实时预览帧率

普通和体素结果共用左右对比区：输入原图在左，当前保留场景的运行截图或交互预览在右。两侧独立切换，机位不强行对应；原图直接取原始上传文件，生成画面来自保留候选。未有输出时仍展示参考图与等待状态，文字输入不保留空白参考列。历史单图记录仍只有真实的一张输入，不补造第二张。

创建入口推荐同一场景的 2–5 张不同机位图片，例如正面、侧面和内部细节。单图继续支持，但会提示补充机位，未见区域需要推断；后端原有最多五张、去重和图片身份契约保持。

进入交互预览后，右上角显示当前 Engine 的提交 FPS 和 p95 提交帧间隔，每 500 毫秒更新最近约两秒窗口。数据来自当前 canvas 的 `forgeax:frame-submitted` 事件，按画布、设备代次和世界身份隔离，帧 ID 只去重，不用跳号推算帧数。它不是父页面动画帧、相机 Update tick、显示器刷新率，也不是历史验收的 `submittedFps`。加载与预热显示等待/采样；隐藏时显示暂停，超过 1.5 秒无提交显示零，不保留旧的高帧率。

FPS 通过独立界面服务装饰正常 `preview-output` 回执：为本机 Engine 预览建立只读代理，仅在发送 HTML 响应时加入冻结的监测脚本；静态资源保持原路径与原字节流，压缩 HTML 单独解码。不会写生成 dist、修改任务或启动另一个生成协调器。原始地址保留作来源；装饰失败保留原预览并明确提示无法提供实时帧率。内嵌和从记录列表打开的独立窗口都使用这条路径。

小预览窗首次折叠已知的场景操作说明面板，避免遮住场景；左上“操作说明”按钮可恢复，原 H 快捷键仍有效。宽屏独立窗口保留原面板默认状态。该行为只针对 `#scene-hud[data-scene-ui="recording-controls"]`，不改变相机、录屏或场景几何。

本次是展示、运行观察和输入建议改动，不表示场景制作质量或渲染性能已经提高。运行时帧率随窗口大小、机位、浏览器、设备和其他负载变化；卡顿还需结合实时 FPS 与帧间隔定位。生成 worker 与已封存评审证据保持原状。
