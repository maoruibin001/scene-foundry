# 规格参数契约修复

规格管线的视觉节点默认使用 cbc5 / hy4flash-dev。其他节点保留各自选择，新增 `parameterRepair` 节点；历史配置未指定该节点时继承资产族节点的模型。不可见的图片、占位分与缺参考图不产生有效还原分。

生成前先检查生成器参数。尺寸别名仅在逐轴对应且与明确数值一致时消费；真实冲突保持待决。零纬度、数量、明确声明的布尔开关/厚度、二维池洞和散布密度按公开契约处理，不静默回退到默认值。设备群必须实际生成请求数量的机柜。

无法确定的路径与描述由一次参数契约补全调用提出显式绑定；真实坐标边界、连接点及适配器暗改诊断触发最多一次定向修正。模型只能给出库内生成器的完整合法参数；不能删除物体、改变其 ID/资产族/原参数/变换或将单体合并成整组。绑定单独保存为 `geometryBinding`；`basis=design_fill` 是设计补全，不是测量或对原文的精确复原。依据及源/有效规格摘要写入 `parameter-repair/parameter-resolution.json`，原规格单独保留。相同源、提示、生成器契约与模型的结果可验证后复用，失败不得通过无限调用碰运气。

既有终态规格可从详情页“按当前管线重建此规格”创建同根续接记录。保持原规格和历史，保留其他节点模型，视觉改用 cbc5；同根已有在途续接时拒绝重复创建。参数待决/代理仍不能确认为完整成品。Engine 运行、视觉评审和用户认可分别记录。

本次原场景真实验证结果见交付报告，不能从单测或预检清零推断已达到画质门槛。普通服务与在途版本不因本改造重启。

几何契约门检查引擎局部点到规格世界坐标的真实换轴/旋转/缩放，拒绝越界路径、零长度段、与显式两点位置不一致的连接，以及适配器对明确绑定参数的再次修改。定向修正只能改动诊断字段，不可替换生成器、修改其他参数或缩短路径来规避检查。一次修正后仍失败即保留证据并停止构建。
