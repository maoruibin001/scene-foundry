# 生成结果优先展示场景

普通场景与体素场景共用相同的结果详情和记录列表。

- 结果详情的标题下首先显示当前保留输出的真实运行主图。点击“在本页交互预览”加载 Engine，可继续在独立窗口打开；管线、模型、原图对照、评分及诊断在场景后面。
- 生成记录中的输出缩略图与“打开场景”按钮直接打开当前可用输出，不必先进入详情。空间草稿、部分场景草稿和布局范围草稿分别标明；未通过的产物仍可查看，不计为成品通过。
- 列表只读取当前页的已保存交付回执，并发最多四个。读取失败可手动重试；不扫描全部历史，也不因打开或刷新列表启动 Engine。
- 点击预览时，仍由正常 `preview-output` 接口重新核验保留输出。页面不使用任务根目录的旧 `previewUrl` 或根截图代替保留候选，也不改变评分、选优和下载规则。
- 启动预览前读取当前渲染占用；录制中或无法核实时显示原因。已打开的页面内预览在后续轮询发现录制占用时暂停。页面隐藏、离开可视区域或打开独立预览也会释放页面内渲染上下文。
- 同一场景输出轮询时保留 iframe 及其父节点，更新说明和按钮；候选身份或预览 URL 变化时才替换画面。异步响应不会覆盖导航后的页面或更新后的任务状态。

这是展示与预览入口改动。可独立更新 UI 静态资源与代理，不需要重启生成 worker；普通/体素 API、队列和数据仍隔离。本次验收使用已有产物，没有新增生成任务、模型请求或质量评估。
