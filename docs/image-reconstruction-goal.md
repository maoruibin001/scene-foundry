# 原图复刻目标与验收依据

输入几张图片后，目标是创建同一个三维场景，尽量复现全部参考图；最低要求是主要可见属性大体一致。创建任务时自动固定这一目标，不增加人工确认步骤。用户明确的文字修改优先于冲突的图片属性，其余属性仍以原图为准。

## 借鉴与实现

[image-blaster 的物体生成说明](https://github.com/neilsonnn/image-blaster/blob/4acb43ba126a12358f71838d1b1a05e856b10eaf/.claude/skills/image-blast-3d/SKILL.md)要求保留物体描述、材质、来源图片和证据，并在提取参考物体时保持原图的色彩、材质和比例。这一做法可以借鉴为明确的原图约束；它本身并不提供本项目的还原准确率保证。

本次保留已有的多视图观察、空间关系、资产证据和实际 Engine 渲染流程，增加以下约束与对照：

| 环节 | 实现 | 带来的改善 |
| --- | --- | --- |
| 创建任务 | 冻结每张原图的顺序和内容 SHA、原始文字修改摘要、允许的局部差异，保存 `reconstruction-goal.json` | 后续生成不能用自己的概括、派生图片或自动扩展替换目标 |
| 生成 | 在现有还原指导中强调所有参考图约束同一个空间，区分可见事实与未知部分的推断 | 明确主体、结构、布局、遮挡与机位约束；不重复建立需求或物体清单 |
| 最终评审 | 在原来的 judge 调用中增加逐张原图对照，不增加独立评审调用 | 总分与“像不像原图”分别可见，不再仅靠分数推断还原成功 |
| 证据校验 | 对照绑定原图 SHA、对应参考机位、实际截图 SHA 和当前构建摘要 | 漏图、错机位、重复截图、旧候选报告不能冒充当前结果 |
| 保留最佳候选 | 快照同时保存和恢复原图目标、对照报告、截图与场景 | 选优后不会显示后来失败轮次的报告 |

灰模阶段仍只检查空间与轮廓，材质和光照属于成品评审。未知背面和绝对尺度不能被当成已观察事实，也不能凭猜测判为满足。

## 怎么判定还原

每张原图分别检查六类可见属性：主体与主要结构、布局比例与遮挡、主要轮廓与构造、主要材质与色彩、整体光照、参考机位与构图。评审直接查看原图和实际运行截图，沿用已有需求与资产证据；这六类属性不是新的物体列表。

| 判定 | 含义 |
| --- | --- |
| 接近参考 | 全部参考图的可见属性接近；不代表像素完全相同 |
| 大体一致 | 主体与主要视觉属性一致，只有局部小比例、裂纹、磨损、零碎装饰差异 |
| 存在明显差异 | 任一参考图的主要属性明显改变；其他视图或属性的优秀表现不能抵消 |
| 未核实 | 对照缺失、依据不足、漏图、错机位、摘要无效，或者只有资产未齐的草稿 |

评审原始结构是 `referenceMatch`：每个条目包含 `referenceIndex`、`referenceSha256`、真实截图文件名 `frames`，以及六个属性各自的 `status` 和具体理由 `reason`。后端校验后将原图、截图和构建摘要绑定到 `image-reconstruction.json`。报告缺失或无效时保留已有输出和原始评分，标记未核实，不为了补报告自动追加模型请求。

详情页把三个问题分别展示：**有没有可运行输出、是否达到现有基础交付门槛、是否与原图一致**。基础交付仍使用原有 70 分标准和 Engine 检查，空间门槛不变。因此基础交付通过、原图对照失败可以同时出现；这种情况不能宣称已达到图片复刻目标。

## 版本与兼容

`image-reconstruction-v1` 目标和 judge 结构进入评审协议指纹。旧任务不补造新目标或新判定，缺少原图对照也不被默认为通过。新的目标和报告必须对应同一候选；详情页检测到构建摘要或目标摘要不一致时显示未核实。

独立仓库继续默认使用 `PATH` 上的本地 `codex`；本次功能不改变模型路由、Engine 版本、调用预算和原有验收数值。既有研究环境的自定义启动器保持其自身配置。

## 已验证与尚未证明

2026-10-08，独立项目和运行版本 rc.221 的隔离副本各通过 44 项定向检查，前端构建通过。检查包括两图与五图的逐图覆盖、错误摘要/索引/机位、重复截图、主要差异不可被平均掩盖、旧任务兼容、同一次 judge 承载报告、70 分判定不变、协议指纹变化，以及最佳候选报告恢复。使用本地模拟评审，没有新增模型调用。

这证明目标约束、结构化报告和证据归属检查已经实现；不证明模型的视觉判断已被独立校准，也不证明生成质量已经提升。提示词约束可以减少目标漂移，但不能保证模型正确理解每一处细节。要确认“大体一样”，仍需要真实完整成品、对应参考机位画面，以及基于固定样本的独立视觉核验。

复杂几何、细碎纹理、材质和相机估计仍可能成为主要误差来源。完善报告不能代替这些生成能力的改进；也不能把灰模、可运行草稿或工程检查通过当作完整场景复刻通过。
