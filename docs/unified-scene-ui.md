# 普通场景与体素场景共用界面

普通入口为 `/#create`，体素入口为 `/voxel/#create`。侧栏的“普通场景 / 体素场景”切换加载相应页面，创建、参考确认、记录筛选和分页、任务详情、停止生成、耗时、评分与执行过程复用同一套组件和样式。

切换页面会清空未提交的本页表单。两种模式的已上传参考图、参考方案和任务分别属于各自的数据目录，不在切换时转移。体素参考方案显式保存 `generationSettings.sceneKind = "voxel"`，确认后启动仍是体素任务。

普通场景保留制作预设和六维权重。体素需要参考图，保留已有验收目标和真实评分维度；普通材质预设不会自动应用到体素。尚未校准的旧固定批次评测入口在体素模式下不可用。

任务详情共用可运行输出、原图对比、空间诊断、评分、过程和下载组件。体素产物存在时附加显示占用格、三角形、实体数量、调色板、生成数据和可编辑 `.vox`。文件绑定当前保留候选目录；网络恢复、继续体素、空间重规划等操作仍按后端提供的真实可用条件展示。

页面共用不合并执行系统。普通请求使用 `/api/*`、`/files/*`；体素使用 `/api/voxel/*`、`/voxel/files/*`、`/voxel/process/*`。真实 Engine 绝对预览地址不改写。两类 worker、队列、调用账本和数据目录仍独立，统一 UI 可以由独立 `ui-server.ts` 发布，不要求重启生成 worker。

验证范围是共享界面和路由。自动化测试覆盖类型冻结、参考确认和启动幂等、API 与文件隔离、停止等写操作不自动重放、体素产物和恢复条件，以及过程页相对模块。真实页面验证可读取现有任务，不需要启动新生成；这不等于重新验证两条生成管线的质量或成功率。
